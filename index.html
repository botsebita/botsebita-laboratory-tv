Compatibilidad y acceso

El catálogo incluye emisiones DASH/DRM, URLs con tokens, fuentes con cabeceras y otros formatos. La aplicación mantiene visibles las entradas y explica sus requisitos de acceso. También reproduce manifiestos DASH que no declaran DRM ni requieren tokens o cabeceras privadas. Para DRM se requiere consentimiento manual y una licencia oficial; no se eluden controles de acceso.

Este proyecto no proporciona la señal ni concede derechos de acceso. El usuario debe contar con autorización y una licencia válida del proveedor. Este aviso no elimina el DRM ni sustituye una licencia.

El desarrollador no controla las emisiones externas ni garantiza su disponibilidad. El usuario es responsable de comprobar sus derechos y cumplir las condiciones del proveedor. Este texto no pretende crear una exención legal absoluta.

Debe ser el endpoint oficial que te proporciona el servicio al que estás suscripto. La app no extrae ni usa los valores kid/k del catálogo, ni genera tokens o credenciales. El servidor debe permitir solicitudes desde el dominio donde publiques la web (CORS).

Botsebita Laboratory TV

Prototipo independiente de interfaz web inspirado en el análisis técnico de un reproductor Android. Carga por defecto la playlist pública comunitaria de IPTV-org. No es una versión oficial ni replica servicios privados.
